# u-tree：个人 U 盘

我的个人资料库，用来在**重装系统或换电脑后快速恢复环境**。
当前主力系统：CachyOS（niri，noctalia）。

## 目录

| 位置 | 内容 |
|---|---|
| [`mywiki/`](./mywiki) | CachyOS 装机手册：软件安装、桌面环境配置、中文输入法、输入法词库 |
| [`niri/`](./niri) | niri 窗口管理器的配置与笔记 |
| [`图/`](./图) | 图片素材（壁纸、截图等） |
| [`文本文档/`](./文本文档) | 零散的文本记录 |
| [`111KDE.md`](./111KDE.md) | KDE 相关笔记 |
| [`U盘目录.md`](./U盘目录.md)、[`u盘2.md`](./u盘2.md) | 实体 U 盘的内容清单 |

## 重装系统后的顺序

1. 阅读 [`mywiki/CachyOS.md`](./mywiki/CachyOS.md)，完成系统基础设置
2. 按 [`mywiki/软件安装相关.md`](./mywiki/软件安装相关.md) 安装常用软件
3. 按 [`mywiki/一键配置桌面环境.md`](./mywiki/一键配置桌面环境.md) 配置桌面
4. 按 [`mywiki/中文输入法.md`](./mywiki/中文输入法.md) 配置输入法，并导入
   [`水杉IME-拼音用户词库.txt`](./mywiki/水杉IME-拼音用户词库.txt)
