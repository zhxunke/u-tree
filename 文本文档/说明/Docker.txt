1. 镜像：相当于一个静态的、只读的模板或蓝图，包含运行应用程序所需的所有文件系统结构和依赖
2. 容器：是镜像的一个运行实例
   可以通过`docker ps`查看运行中的容器- 镜像是静态的、不可变的     容器是动态的、可操作的
- 一个镜像可以创建多个容器实例


1. 获取镜像      docker pull [镜像名称]:[标签]     
	docker pull ubuntu:20.04     如果不指定标签，默认使用`latest`标签

2. 运行容器     docker run [选项] [镜像名称] [命令]
	-d: 后台运行     #
	 -it: 交互式终端      # 
	 --name: 指定容器名称    #
	 -p: 端口映射(主机端口:容器端口)      #
	 -v: 卷挂载(主机目录:容器目录)
docker run -it --name my_container ubuntu:20.04 /bin/bash

3. 容器生命周期管理 *
   启动已停止的容器**： docker start [容器ID或名称]       **
	重启容器**：   docker restart [容器ID或名称]      **
	删除容器**：docker rm [容器ID或名称]
	删除镜像**： docker rmi [镜像ID或名称]

4. 查看容器信息
   列出运行中的容器： docker ps      
   列出所有容器(包括停止的)： docker ps -a  
	查看容器日志：  docker logs [容器ID或名称]

5. 进入运行中的容器
   docker exec -it [容器ID或名称] /bin/bash

## 完整示例流程
1. 拉取Ubuntu镜像：
   docker pull ubuntu:20.04

2. 运行交互式容器：
   docker run -it --name my_ubuntu ubuntu:20.04 /bin/bash
3. 在容器内执行命令(如安装软件)：
   apt update && apt install -y curl
4. 退出容器(但容器停止)：
   exit
5. 重新启动容器：
   docker start my_ubuntu
6. 进入运行中的容器：
   docker exec -it my_ubuntu /bin/bash
7. 停止并删除容器：
   docker stop my_ubuntu
   docker rm my_ubuntu
8. 删除镜像(可选)：
   docker rmi ubuntu:20.04
通过理解镜像与容器的关系以及这些基本操作步骤，您就可以开始使用Docker来部署和管理应用程序了。
