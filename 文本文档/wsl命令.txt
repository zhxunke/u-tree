安装与更新
wsl --install	     默认安装 WSL 和 Ubuntu                             
wsl --install -d <发行版名>	安装指定发行版（如 Debian、kali-linux）            
wsl --update	更新 WSL 内核版本                                               
wsl --status	查看 WSL 版本和运行状态

发行版管理
wsl --list 或 wsl -l	列出已安装的发行版                               
wsl --list --verbose 或 wsl -l -v	显示详细信息（包括 WSL 版本）
wsl --set-default <发行版名>	设置默认发行版              
wsl --set-version <发行版名> 2	将发行版转换为 WSL 2     
wsl --unregister <发行版名>	彻底删除发行版（谨慎操作！）     
wsl --shutdown	强制关闭所有 WSL 发行版

启动与运行
wsl 或 wsl ~	启动默认发行版（用户主目录）                       
wsl -d <发行版名>	启动指定发行版             
wsl --list   查看清单                                       
wsl --set-default 系统名        切换默认系统                           
wsl --terminate <发行版名称>          关闭指定 WSL 发行版的命令
wsl -u root	以 root 用户启动                                              
wsl -e <命令>	直接执行命令后退出（如 wsl -e ls /） 
 
 备份原镜像列表
 cp /etc/pacman.d/mirrorlist /etc/pacman.d/mirrorlist.backup
# 清华大学镜像源
echo 'Server = https://mirrors.tuna.tsinghua.edu.cn/archlinux/$repo/os/$arch' > /etc/pacman.d/mirrorlist
# 或使用阿里云镜像源
echo 'Server = https://mirrors.aliyun.com/archlinux/$repo/os/$arch' > /etc/pacman.d/mirrorlist
# 或使用中科大镜像源
echo 'Server = https://mirrors.ustc.edu.cn/archlinux/$repo/os/$arch' > /etc/pacman.d/mirrorlist

# 安装 reflector
pacman -S reflector
# 生成中国境内的最快镜像列表
reflector --country China --sort rate --save /etc/pacman.d/mirrorlist

文件系统互通
Windows 访问 WSL 文件	在文件资源管理器输入 \\wsl$\<发行版名>\        
WSL 访问 Windows 文件	Windows 磁盘挂载在 /mnt/ 下（如 /mnt/c/Users）
explorer.exe .	在 WSL 中打开当前目录的 Windows 文件资源管理器

网络与代理
cat /etc/resolv.conf	查看 WSL 使用的 DNS
export http_proxy=http://<IP>:<端口>	临时设置代理（需替换为 Windows 主机 IP）            
 用户与权限
sudo <命令>	以 root 权限执行命令                          
sudo passwd root	设置 root 密码                    
whoami	查看当前用户

实用工具命令
wsl --export <发行版名> backup.tar	导出发行版到备份文件                      
wsl --import <新发行版名> <路径> backup.tar	从备份恢复发行版
wsl --help	查看所有支持的 WSL 命令

快速进入 WSL 并切换到项目目录
wsl ~ -d Ubuntu -e cd /path/to/project && bash

从 Windows 调用 WSL 命令
wsl -e ls -l /home

备份 Ubuntu 发行版
wsl --export Ubuntu ubuntu_backup.tar
